HW2 - CS2 - Media Database                                        100 Points Possible
========================================================================
Media Database

Background:
Learning how to create a simple database using classes will aid in understanding additional concepts with object-oriented programming. We will be expanding HW1 (movie database) to now handle various media types (movie, tv, music, etc).

Tasks:
1. Create a folder named HW2 under your Assignments folder.
2. Copy over the files you created in HW1 into your HW2 folder.
3. main.cpp will still be the driver for your program.
4. Create the following files: 
   - media.h, media.cpp
   - tvshows.h, tvshows.cpp
   - music.h, music.cpp
5. Create a Makefile and configure it to compile all cpp files.

Using techniques discussed in class and labs, create the following:
1. Inside of **media**, you will have a namespace called `media`.
   - A class called `Media`.
   - Every media will have several standard attributes that you will need to store. These are `id`, `title`, `year`. You will need to move those out of your movie class so there is only one copy of each.
   - Attributes should be private or protected.
   - You will need to create virtual functions inside of Media to require derived classes to inherit. This includes a virtual function `displayInfo` which should return a string.

2. A namespace called `movies`.
   - A class called `Movie`.
   - `Movie` should inherit `Media`.
   - Each movie should have the following variables: `genre`, `rating`, and `director`.
   - There should be appropriate methods to get and set variables, and all variables should be private.
   - Assume that all variables will have one value for each movie, i.e. only one director or only one genre type.

3. A namespace called `tvshows`.
   - A class called `Tvshow`.
   - `Tvshow` should inherit `Media`.
   - Each tvshow should have the following variables: `genre`, `rating`, and `numEpisodes`.
   - There should be appropriate methods to get and set variables, and all variables should be private.
   - Assume that all variables will have one value for each tvshow, i.e. only one genre type.

4. A namespace called `music`.
   - A class called `Music`.
   - `Music` should inherit `Media`.
   - Each music should have the following variables: `composer`, `genre`, `numTracks`, and `totalPlaytime`.
   - There should be appropriate methods to get and set variables, and all variables should be private.
   - Assume that all variables will have one value for each music, i.e. only one genre type.

5. A class called `Database`.
   - You will typically have one database for this assignment.
   - The database should have the following variables: `name`, `db_id`, arrays for Movies, Music, and TVShows (as pointers).
   - The database should have the following functionality:
     - Add or remove specified media given an ID.
     - Display all media of a given type (using `displayInfo`).
     - Search for media given title, genre, etc., and print out a nicely formatted table.
   - For this assignment, your database can create an array of 100 movies (i.e., `movies::Movies* movieList[100];`), 100 tvshows, and 100 music, and assume that there will never be more than 100 of each of those tracked at one time.

6. Read in the movies from a file.
   - You can use a sample list of media from here: https://github.com/jeremybergen/CSCI112/tree/main/Assignments/HW2. Feel free to add your own media to the list in the same format.
   
7. You should have a simple menu-driven interface to allow a user to manually:
   - Add in movies, delete media, print out media, or write out the entire database to a different CSV file.
   - This should be coded inside of `main`.

8. Update `README.md`.

9. Submit a screenshot to D2L of your program running.

10. All code must be uploaded to GitHub.

11. Follow standard coding styles, including adding comments as necessary to clarify complex sections of code.
